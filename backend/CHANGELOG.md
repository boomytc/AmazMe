# Changelog

## 0.1.0

- 建立独立 Python Host、会话 worker 与执行监督器，不依赖旧 TS 业务内核。
- 提供 Web 客户端、DeepSeek Flash 流式调用及受管 VM 文件/shell 工具。
- 使用 SQLite 事务请求去重、事件恢复、取消与未知副作用记录。
- 通过容器执行域和持久清理回执限制 worker 替换，拒绝旧 Host 代际和不同构建控制。
- 提供包内 Python、Lima 与离线镜像的本机独立 onedir 及实际运行验收工具。
- 收敛重复取消、并发 worker 分配、断连任务容量回收和 VM 删除互斥；补齐丢回执、断网、会话切换与快照恢复验证。
- 只读快照在 worker 退役后返回会话重启预算耗尽，关闭监督器时先放开控制锁再等 worker 退出。
- 已完成的根任务可以分支成新会话。分支只复制该任务的上下文，之后两边的新消息互不可见，父会话历史保留。
- 会话可以归档。归档拒绝新的提交和分支，取消尚未开始的任务，已有记录保留；恢复后才能继续。
- 已完成的上下文可以压缩。摘要只在依据仍匹配时落盘；压缩失败或依据过期都不改写原来的消息。
- 模型目录只列出当前能调用的供应商。保存选择时保留 API key 和已有会话，端点必须是不含凭据的 https 地址。
- 供应商请求可以走指定代理并附加请求头。代理密码不出现在设置回执和会话记录里，Authorization 这类头不能被覆盖。
- 页面可以浏览授予工作区里的文本文件，并按当前摘要写入。越界符号链接、硬链接、过期摘要和更新冻结都不会改文件。
- 模型的 read_file / write_file 在客户机脚本里拒绝越界符号链接、符号链接目录和硬链接。写入中断时尽量写回原内容。
- 终端在客户机里打开 PTY。输出超过窗口后要等客户端授信，退出码只来自 waitpid；控制连接断开不会被当成进程已经退出。
- MCP stdio 服务由监督器放进客户机。工具调用先等批准才转发；同一调用的不同参数会冲突。停止进程后的退出码来自 waitpid，清理未证实时不能再开新的 MCP。
- 远端 daemon 要核对主机密钥、daemon 内容和代际。本地连接断开不会把远端记成已停止，未完成的调用保持未知且不会重放。
- 脚本在 QuickJS 里运行，只能通过 bridge 调用受控工具和读写本次状态。成功才提交状态；失败、超时、取消和没有退出证明都不提交。没有退出证明时，同一会话不能再开新脚本。
- 历史搜索只读取当前会话已经落盘的任务和消息。别的会话不会混进来，归档后仍可搜索。
- 插件只声明身份、配置和固定 stamp 入口。监督器启动该入口；插件碰不到 SQLite。会话里还有未结束的任务，包括定时等待，就不能登记或重新加载。
- 额外工作区必须显式授予。主目录仍在 /workspace，其他目录固定映射到 /grant/名称。文件、工具和终端使用同一条路径，不会默认挂上用户主目录、SSH 密钥或钥匙串。
- 记忆按工作区保存。模型调用只注入当前会话工作区里与用户原文相配的记忆，其他工作区的记忆不会进入上下文。
- 受检写入前会记下文件的原内容。可以预览与当前文件的差异，再按当前摘要只恢复这一条路径。
- 定时任务用 IANA 时区计算到期时刻。不存在的本地时间和含糊的夏令时不会猜。到期后只由一次调度写入提交回执，重复触发不会再交一份。
- 工作流把检查和修正放进独立子任务。未通过时最多再开有限次修正；同一结论重复提交不会多开子任务。取消工作流会取消子任务，只取消子任务不会取消工作流，也不会补一个新的。恢复阶段只读已保存的进度。
- 网页搜索和抓取默认关闭。请求只带已保存的 DeepSeek API key，不转发聊天代理、附加请求头或模型给出的端点。响应超过上限，或连接在计费请求发出后中断，都保持未知并且不会用同一个调用再发一次。
- 模型可以调用 web_search 和 web_fetch。这两次调用留在会话 worker 里，不打开客户机。策略没开或没有 DeepSeek key 时不会发出请求，也不会占住调用 ID。同一步骤的重试，以及已经记成未知的调用，都不会再发。
- 桌面观察默认关闭。点击坐标按驱动报告的方向和比例换算，过期或被替换的截图不会发出。驱动中途退出的动作保持未知，没有退出证明时不能再观察；确认清理后才恢复。
- 项目、显示名、反馈和会话分享按新格式保存。同一 ID 的不同内容会冲突。导出不附带供应商密钥；导入只接受 amazme-export/1，不覆盖已有会话，也不读取旧记录。
- 管理面板打开时读取已保存的项目列表，不把刚提交的名称当成全部项目。
- 分享当前会话后，面板再读取已保存的分享正文，而不是只显示刚提交的回执。
- 打开插件面板时读取已保存的插件，不把刚登记的名称当成全部插件。
- 打开网页面板时读取已保存的策略。再次保存沿用原来的端点和条数，只改启用开关。
- 指定包内 Python 后端时，桌面端启动它并用控制令牌关机和冻结更新。关掉窗口不会停止共享后端，明确退出才会。配对码写在该窗口自己的会话里。
- 安装包带上桌面驱动、终端门闩、MCP、插件、远端和脚本助手。冻结后的 serve 才能在安装目录里启动。
- 命令行、JSON-RPC 和异步 SDK 都要写明宿主、会话和工作区。松开绑定不会取消任务。
- 终端界面写明宿主、会话和工作区。Ctrl-C 只松开这次绑定，不取消会话里已经接受的任务。
- 桌面每个窗口在地址里写明会话和工作区。新窗口另开一个会话，不附到列表里的第一个。关掉窗口只松开这个窗口的绑定，不取消已经接受的任务。

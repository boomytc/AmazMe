# Changelog

## 0.1.0

- 建立独立 Python Host、会话 worker 与执行监督器，不依赖旧 TS 业务内核。
- 提供 Web 客户端、DeepSeek Flash 流式调用及受管 VM 文件/shell 工具。
- 使用 SQLite 事务请求去重、事件恢复、取消与未知副作用记录。
- 通过容器执行域和持久清理回执限制 worker 替换，拒绝旧 Host 代际和不同构建控制。
- 提供包内 Python、Lima 与离线镜像的本机独立 onedir 及实际运行验收工具。
- 收敛重复取消、并发 worker 分配、断连任务容量回收和 VM 删除互斥；补齐丢回执、断网、会话切换与快照恢复验证。
- 只读快照在 worker 退役后返回会话重启预算耗尽，关闭监督器时先放开控制锁再等 worker 退出。
- 已完成的根任务可以分支成新会话。分支只复制该任务的上下文，之后两边的新消息互不可见，父会话历史保留。
- 会话可以归档。归档拒绝新的提交和分支，取消尚未开始的任务，已有记录保留；恢复后才能继续。
- 已完成的上下文可以压缩。摘要只在依据仍匹配时落盘；压缩失败或依据过期都不改写原来的消息。
- 模型目录只列出当前能调用的供应商。保存选择时保留 API key 和已有会话，端点必须是不含凭据的 https 地址。
- 供应商请求可以走指定代理并附加请求头。代理密码不出现在设置回执和会话记录里，Authorization 这类头不能被覆盖。
- 页面可以浏览授予工作区里的文本文件，并按当前摘要写入。越界符号链接、硬链接、过期摘要和更新冻结都不会改文件。
- 模型的 read_file / write_file 在客户机脚本里拒绝越界符号链接、符号链接目录和硬链接。写入中断时尽量写回原内容。
- 终端在客户机里打开 PTY。输出超过窗口后要等客户端授信，退出码只来自 waitpid；控制连接断开不会被当成进程已经退出。
- MCP stdio 服务由监督器放进客户机。工具调用先等批准才转发；同一调用的不同参数会冲突。停止进程后的退出码来自 waitpid，清理未证实时不能再开新的 MCP。
- 远端 daemon 要核对主机密钥、daemon 内容和代际。本地连接断开不会把远端记成已停止，未完成的调用保持未知且不会重放。
- 脚本在 QuickJS 里运行，只能通过 bridge 调用受控工具和读写本次状态。成功才提交状态；失败、超时、取消和没有退出证明都不提交。没有退出证明时，同一会话不能再开新脚本。

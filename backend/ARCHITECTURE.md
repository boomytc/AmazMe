# Python 后端的本机执行与状态所有权

执行契约见[本机方案](../docs/python-backend-plan.md)。

| 模块 | 所有权 |
| --- | --- |
| host / host_store | profile、Host 代际、持久投递、客户端绑定、设置、工作区与更新 |
| storage / session_domain | 单会话 writer、事务去重、上下文、审批、调用意图、取消和结果 |
| worker | 驱动会话状态机；通过监督器执行工具 |
| supervisor | 受管进程、执行代际、调用回执、资源清理及重启预算 |
| native_execution / native_services | 本机执行授权、进程登记、服务及真实退出核对 |
| pty_gate / mcp_gate | PTY 与 MCP 协议、直接子进程和已知后代生命周期 |
| processes | 固定进程的租约和继承锁，核对进程退出 |
| workspace_files | 本机文件路径、摘要和冲突校验 |
| providers / accounts / oauth | 模型协议、账号配置、凭据和授权身份 |
| streams / web | 连接身份、有界事务重放、ACK、快照和迟到响应隔离 |

Host、worker、监督器分别拥有自己的数据库。先持久登记意图再产生副作用，重试使用同一调用身份；未知效果不自动重放。取消受理与资源已退出分别核对。

本机 shell 具有当前用户权限。文件路径限制与审批不构成操作系统沙箱；凭据不传入普通工具环境或日志。
PTY、MCP 和插件按会话归属，不随页面断开或一次模型回复结束而关闭。MCP 支持 stdio、HTTP、OAuth 和媒体结果；工具目录及审批绑定实际调用身份，迟到结果不能覆盖未知事实。

桌面关闭窗口由用户偏好和活动任务确认决定。明确退出先阻止新投递，再取消任务并停止本应用拥有的服务；Worker 退出后还会取消未由存活 Worker 持有的持久任务。清理失败保留重试入口，不宣称成功。恢复窗口读取原会话与设置。

当前执行库不自动读取、迁移或删除旧用户历史库。资源普查用于开发与验证，不提供第二种执行后端，也不自动删除未知资源。

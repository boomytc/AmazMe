# Python 后端的本机执行与状态所有权

现行契约以 [本机优先方案](../docs/python-backend-plan.md) 为准，2026-10-24 替代 VM 默认执行设计。

| 模块 | 所有权 |
| --- | --- |
| host / host_store | profile、Host 代际、持久投递、客户端认证/绑定、更新、工作区与检查点 |
| storage / session_domain | 单会话 writer、事务/去重、上下文、审批、调用意图、取消和结果 |
| worker | 驱动会话状态机；调用监督器，不自行启动 shell |
| supervisor | 受管进程、执行授权代际、调用回执、已知资源核对、重启预算 |
| 本机执行模块 | 登记后放行，直接子进程/可追踪后代，超时、取消、有界输出和退出 |
| native_services / pty_gate / mcp_gate | 固定 PTY/MCP runner 持有生命周期锁和后代观测；各 gate 负责各自协议及直接子进程真实退出 |
| processes | 固定 Host/worker/监督器/执行 runner 的继承锁；只证明这些固定进程自身退出 |
| workspace_files | 本机文件读写、完整摘要、冲突保护；应用层路径限制不等于 shell 沙箱 |
| streams / web | 客户端连接身份、有界事务重放、ACK、快照和迟到响应隔离 |
| providers | 真实供应商与 faux；凭据不传入执行环境或普通日志 |

Host、worker、监督器分别拥有自己的数据库。先提交意图再产生副作用，未知效果不能自动重放。
执行结果与已知资源状态分别保存：取消请求不是退出，停止已知资源不是证明任意脱离后代消失。
监督器重启核对稳定调用 ID、归属与进程出生身份；旧控制命令比较 Host/worker/执行代际。
正常命令真实退出后可结算；具体无法核对的资源标记 stop_unconfirmed，结果 unknown 保持原状。
已知冲突按作用域拒绝，不以整台 VM 停止证明作为准入条件。

PTY、开发服务、MCP 明确归属会话，生命周期不绑定一次模型回复或页面连接。
普通命令的退出回收与长驻资源的显式关闭分开处理。停止后端/更新时按登记逐项停止。
PTY 输入在发送前持久登记 ID；未知写入不重放，确认排入终端不代表命令执行完成。
终端按会话列举与重连。协议窗口仍是 32 KiB，监督器按已读字节归还信用；重连记录是最多 256 KiB 的解码文本和 `output_seq`。页面按这个序列解释光标、换行和清屏。已退出或失联的同 ID 不能重新执行。
`amazme-backend tui`、print/JSON CLI、`--mode rpc`、Python SDK 和默认 `amazme` 交互画面使用同一会话接口。等待审批时只接受明确决定，不会自己代替用户决定。离开、松开绑定或进程退出不关闭会话终端或 MCP；显式关闭才会停止。它们展示、转发或读取最近的可见输出，不是完整终端模拟。
`amazme-backend client submit` 只等待终态。`client decide` 在连接前要求整词「批准」或「拒绝」，并且只能指向一个请求或一次 MCP 调用；它使用服务端保存的摘要。已经结束的调用再次决定只返回原结果，不再执行。决定后松开自己的绑定。
模型选择请求不携带密钥。更换或清除密钥使用单独入口和期望代际；过期写入、同时写入和更新冻结都不会覆盖已保存的密钥。模型调用在发送前重读密钥，密钥已清除则不创建供应商连接。记忆正文含当前供应商密钥时拒绝保存，错误文本不含密钥。已经落盘的这类记忆仍留在库里，但不会放进模型上下文。定时任务和工作流检查同样拒绝含当前密钥的新正文。已经到期的这类定时任务记为未知且不再投递，正文仍可由当前用户读到。已经排队且含当前密钥的工作流检查不会进入模型，该子任务记为未知；用户本轮输入仍会发送。压缩原文含当前密钥时不请求摘要，返回的摘要含当前密钥时不写入；已经落盘且含当前密钥的摘要不会进入下一轮模型输入。失败不删原消息。网页查询或地址含当前密钥时不发送、也不占用调用。原话含当前密钥时不附带原话，查询本身仍可发送。插件门、Codemode 和桌面驱动只拿到工具环境，不继承供应商密钥、控制令牌或 SSH agent。
导入在写入前核对每个会话的工作区和项目，以及反馈指向的会话。缺任何一项时不创建项目、会话、反馈或正文。
分支在写入前核对父会话工作区。复制失败时删掉未打开的会话及其项目关联，父会话保留。分支会复制网页和桌面开关。已发出的网页调用和被挡住的桌面运行状态留在父会话。地址无效时不分出新会话。
会话里的文件工具如果没有写明 grant/名称，就读写该会话的工作区。显式 grant/名称 仍指向那个目录。准备写入时的摘要和检查点也按这个目录计算。
侧栏在选中会话后显示该会话工作区的本机目录。文件区另显示当前浏览目录。未选会话时侧栏写「本机工作区」。
页面新建终端和连接 MCP 不提交文件区正在看的目录。工作区留空时，宿主按该会话的目录打开。显式写入的工作区名称仍指向那个授予目录。
宿主在打开终端、MCP、脚本、远端或插件调用之前先确认会话存在。没有这条会话时不联系监督器，也不会落到主工作区。
宿主库里已经有会话表时，缺少这一行会使监督器拒绝 shell，以及终端和 MCP。写明工作区名称也会先核对这一行，通过之后该名称仍指向那个授予目录。不会改用主目录。库文件或会话表还不存在时，监督器单测仍把目录当作 primary。
取消授予不删除目录里的文件，也不把会话改到主目录。授予已经取消，或定时记录里的工作区与会话当前目录不一致时，到期任务记为未知且不再提交。此后也不能再为该会话新建定时任务、打开新的工作流或追加修正子任务。已有工作流仍可重读、重放原结论、通过或取消。
执行库存储失败也必须关闭已持有的进程句柄；无法记录的结果保留不确定状态。
MCP 服务在私有启动许可后才执行用户命令。工具目录保存 inputSchema，调用参数保留原始 JSON 类型。
审批摘要绑定服务、命令、工作区、构建、工具和参数；先持久登记 `running` 再发出调用。
慢响应保持 `running`，监督器独立接收结果；页面重连查询回执。关闭/失联后没有结果的调用保持 `unknown`，
迟到结果不能覆盖取消时已登记的未知事实。未知调用不重放，已关闭的同一服务 ID 不重新启动。
模型只看到本回合已连接服务的工具别名。别名在流式返回前绑定到该步的目录快照；审批摘要包含服务、命令、工作区、构建、工具、schema 摘要、调用 ID 和 JSON 参数。
调用 ID 在首次发送前落盘。恢复查询同一调用，unknown 不重发。取消一次调用不关闭服务，也不停止其他会话的服务。
目录与已审批 schema 不一致时拒绝发送，不静默替换目标。未决调用上限 512，同时进行上限 16，全部身份上限 4096；查询保留全部未决调用和最近 100 条终态，不删除旧身份。
连接后的动态目录刷新、HTTP/OAuth 和媒体呈现尚未实现。
认证、审批、签名、公证、系统权限和凭据保护保留。原始 shell 具有当前用户权限，不承诺沙箱。

执行库是本机专用格式，旧 VM 执行库拒绝读取写入；不删除或自动转换用户历史文件。
VM/cgroup/容器证明和 guest 路径不进入新契约。改造中的功能状态以验收台账为准，未验证不标完成。
资源普查只服务构建和验证入口，不是第二种执行后端；它不删除用户 profile，也不为了清理去安装或启动虚拟机。

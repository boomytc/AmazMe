# 会话轨迹与下一步建议

## 设计约束

默认阅读结论，需要时展开执行过程。连续思考与工具调用形成一个过程组；用户消息、助手正文和通知保留原顺序与边界。不归类重排工具，不改持久化历史，不从思考文本推断任务阶段。

过程组默认收起；运行时展示当前动作，结束时展示调用与思考计数。运行中失败并自行修正是正常过程：被后续成功步骤解决的失败只计入摘要（`{count} 个步骤失败后已继续`），不改变组的状态；只有运行未解决的失败（最后一次成功之后的失败）、中断或缺失结果才升级为组级红色提示，关键诊断在收起时可见。单条失败卡片始终保留自己的失败标记，不因组状态而淡化。审批保留在独立审批区。手动展开不随新事件折回，刷新保留焦点、选区和视口；分支切换重置页面展开状态。

工具摘要优先展示命令或文件对象，完整参数和结果始终在详情中可查看、复制。复杂 shell 文本不伪装成语义摘要。

输入框保留简短稳定的基础提示，下一步建议是独立、可撤下的草稿候选：候选以淡色幽灵文本落在输入首行，只有旁边的「Tab 接受」和撤下按钮可点，因此指向输入框的点击仍然是落光标。Tab 或点击接受只填入草稿；Enter 仍由用户发送。命令补全优先，Shift+Tab 保留导航，输入法组词期间不接受建议或提交，Esc 在对话任意焦点位置撤下候选。候选属于它对应的那条回答：切到设置或弹窗只是暂时不显示，回来后仍是同一条；只有来源变化（新的最终回答、会话、分支、模型或语言）才替换或丢弃，同一来源不重复请求。



建议只依据当前轮用户目标、最终回答和执行状态，不读取完整思考轨迹。不建议删除、提交、推送或执行代码等授权动作；证据不足或助手在等待澄清时不提供。宿主从当前对话验证回答条目，使用当前模型生成，输入限制为用户问题前 2000 字符与答复后 6000 字符；最多 256 输出 token、12 秒超时，不提供工具。生成不阻塞对话，失败回退到基础提示。候选只接受单条短文本，拒绝命令和授权类措辞；它始终只是草稿，不作为安全授权。切换会话、分支、开始新轮或输入内容时作废旧结果。提供持久化开关。

## 验证

每阶段运行受影响包的构建，再运行包测试；针对分组边界、异常、焦点、键盘冲突、过期请求和开关补充回归。最终用真实浏览器在桌面宽度（如 1024 与 1440）下验证长轨迹与浅深主题，修复后再次验证。

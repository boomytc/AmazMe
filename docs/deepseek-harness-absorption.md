### 模型流等待与取消

`3af898f` 在现有 lazyStream 边界统一约束初始化、下一事件和结果等待，把独立的 `idleTimeoutMs` 接入 Models、产品 ModelRuntime、组合供应商、SDK 和 Durable，复用已有 HTTP 空闲设置。收到 HTTP 响应头不再意味着后续等待不受约束；空闲超时走现有可重试错误，调用方取消保持 aborted。没有新增第二套 Scheduler 或 provider 专用计时状态。

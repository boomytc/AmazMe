# Web 客户端的区域、布局与呈现

本包是 Web 与 Electron 共用的页面。会话、账号与执行状态归 Python Host 所有；这里只决定界面如何承载和呈现它们。窗口原生外观（标题栏、红绿灯、拖拽）归桌面壳，页面画的是同一条 `titlebar`。区域、布局、组件与文案的约定如下；与本页不符的实现按「本轮收敛」逐项收口。

## 区域职责

| 区域 | 尺寸 | 承担 | 不承担 |
| --- | --- | --- | --- |
| `titlebar` 标题栏 | 48px | 当前视图的上下文与动作：标题、运行态势、侧栏开关或管理返回、会话内搜索、分叉、停靠栏开关、审批提醒；桌面壳内同时是窗口标题栏（macOS 红绿灯内嵌、整行可拖拽） | 列表操作、全局导航 |
| `app-rail` 应用栏 | 56px | 全局目的地（对话、插件、技能、自动化）、品牌与连接状态、设置入口 | 列表操作、当前会话的上下文 |
| `sidebar` 侧栏 | 268px | 仅对话视图的会话导航：新建会话、筛选、项目与会话分组 | 全局导航；项目编辑在项目行菜单里 |
| 主列会话流 | 余量 | 唯一滚动区：消息、工具过程、审批卡、提问表单 | 固定标题栏与输入区 |
| 主列输入区 | 内容高度 | 草稿、附件、权限、模型、队列与命令面板 | 接管会话流滚动 |
| `dock` 停靠栏 | 380px | 当前会话的伴随工具，页签即该工具的标题 | 重复页签标题、全局导航 |
| 管理视图 | 主列 | 插件、技能、自动化与设置的整页呈现；此时隐藏侧栏与停靠栏，返回对话在 `titlebar` | 悬浮窗式设置 |
| 浮层 | 视口 | 菜单、选择器、弹窗、命令面板；不改动下层布局 | 常驻状态 |

侧栏只在对话视图出现；进入管理视图后由 `titlebar` 的返回入口回对话。折叠侧栏后，`titlebar` 提供唯一的展开入口，侧栏头部不再重复这个开关。

## 布局规则

- 窗口第一行是跨全宽的 `titlebar` 48px；其下四列：应用栏 56、侧栏 268、主列余量、停靠栏 320–380。桌面最小窗口 1184（`packages/gui/src/main.ts`），更窄的窗口不作为版式目标。
- `titlebar` 横跨所有列，按窗口宽度排布，不随侧栏或停靠栏开合换行；标题单行省略，运行态势放标题下方。
- 桌面窗口外观由壳决定：macOS 用 `titleBarStyle: hiddenInset` 和固定的红绿灯坐标，页面只在 `:root[data-desktop="darwin"]` 时给 `titlebar` 留出 78px 的交通灯内嵌，并让别的平台与浏览器模式保持普通单行工具条。`titlebar` 是拖拽区，按钮与输入框是 `no-drag`；窗口底色跟随页面 canvas（`amazme:set-window-background`）。
- 窄窗口先让宽度给会话：窗口不足 1280 时打开停靠栏会收起侧栏；停靠栏按 `clamp(320px, 窗口 - 884px, 380px)` 收窄，侧栏折叠后按 616px 计算。
- 滚动只发生在四个容器里：`session-list`、`transcript`、管理视图、`dock-body`。标题栏、应用栏、侧栏头部、输入区、停靠栏头部固定。
- 会话流与输入区共用一条内容轴：`--column-max: 768px`，由 `center` 的容器宽度决定，而不是窗口宽度。
- 空状态占满主列，标题与输入区的垂直关系固定；空状态最多一句可操作说明，不与输入区占位符说同一件事。内联空状态只有一套排版（`.empty-state` 组），侧栏、面板、连接列表与选择器只保留内边距和对齐差异。
- 标题层级由 `tokens.css` 的类型尺度承担：欢迎页 30/38、欢迎卡 24/32、管理页面 22/30、弹窗 17/24、停靠栏面板 15/20、分组 14/22；分区标签 12/500，元信息 12。停靠栏页签已经是标题，面板内不再出现同名 H1。
- 面板头只有一份实现（`react/panel-head.tsx`）：停靠栏与管理页共用标题、描述与动作的排布；标题为空时只渲染其余部分。
- 浮层不推动布局；打开菜单、选择器或弹窗时，下层区域不重排。

## 组件规则

- 图标按钮按使用场景分三档：32（标题栏、侧栏头部、面板动作）、28（行内与菜单）、22（紧凑清除），由 `.icon-button` 与 `--compact`、`--mini` 修饰符实现。同一档共用圆角、悬停、展开、禁用与焦点样式，尺寸以外的位置由各组件自己负责。
- 行：会话行 36、面板行 38、项目行 36，统一 `--radius-md`；选中态只用 `--active`。
- 页签：停靠栏页签 28，管理分类沿用 38 的行式导航；页签承载标题与选中态，不额外加说明文字。
- 选中态统一用 `--active` 底：停靠栏页签、导航行、会话行一致；展开态、悬停态各自用 `--hover`，不叠加卡片阴影。
- 卡片：`--radius-xl` 加发丝线或 `--shadow-card`；浮层用 `--raised`、`--shadow-popover`、`--radius-md`。
- 输入：常规 32、筛选 30、设置字段 40。宽度随栏宽，控件高度不随内容变化。
- 状态色只表达语义：`--danger` 失败、`--warn` 需要注意、`--success` 已连接或已保存；不让 `--diff-add` 兼任状态色。
- 标题栏是一条不可换行的工具条：标题单行省略，状态在标题下方；桌面壳内整行可拖拽，交互控件标记 `no-drag`。
- 焦点环只有一套：`--focus-ring`、`--focus-ring-offset`，被滚动或浮层裁切的行走 `--focus-ring-inset`；字段聚焦是强调边框加 `--focus-shadow`。
- 间距按 `--space-2` 到 `--space-24` 的 2px 尺度；层级按 `--z-brand`、`--z-jump`、`--z-quote`、`--z-combobox`、`--z-tooltip`、`--z-popover`、`--z-menu` 命名。
- 暗色配色覆盖全部随主题变化的 token，包括开关手柄与阴影。

## 文案规则

术语表：

| 概念 | 用词 | 不采用 |
| --- | --- | --- |
| 窗口顶部的一条工具条 | 标题栏 / titlebar | 顶部导航、nav bar |
| 一条持久会话 | 会话 / session | 聊天、对话 |
| 对话界面本身 | 对话 / conversation | 会话（指界面时） |
| 项目根 | 项目 / project | 工作区（内部路径概念才叫工作区） |
| 右侧伴随工具 | 停靠栏 / dock | 会话工具、侧栏 |
| 停靠栏内的一页 | 面板 / panel | 页签 |
| 管理视图 | 管理 / management | 设置（只指设置页） |

- 标题不重复：页签即标题时不再渲染同名标题；分区标签不复述紧邻的按钮或内容。
- 能用布局与组件表达的，不写成句子：计数用 `1–22 / 22`，快捷键进快捷键面板，操作结果由控件状态表达。
- 设置项描述至多一句，不复述 label；教学性长文（cron、时区、统计口径）放 tooltip 或折叠区。
- 占位符是动作短语，`aria-label` 才是完整说明；同一输入的两个属性不写同一串文案。
- 状态文案收成两档：等待你的决定 / 已连接、运行中这类事实。同一事实不在标题栏、面板与统计里各写一套。

## 收敛记录

- 实现：移除旧 DOM 渲染器的兼容入口与静态骨架里 React 不再渲染的管理占位，页面只保留 React 一条实现；标题栏与主题重复下发一并收口。
- 外壳：原生标题栏并入跨全宽的 48px `titlebar`（macOS `hiddenInset`，红绿灯内嵌、整行拖拽、窗口底色随 canvas）；侧栏折叠键上移，管理返回入口统一到 `titlebar`，管理页不再各自带返回。
- 导航一致性：会话工具快捷键改名并改用真实行为文案；侧栏导航与设置入口补齐 `aria-current`；连接与保存状态改用 `--success`，不再借用 diff 色。
- 文件导航：dock 文件路径改为单行自适应面包屑，宽度不足时先收标签再折叠中段，悬停就地展开，不再换行。
- 行尾：会话行的时间与「更多」菜单共用一个 28px 尾部槽位，后者覆盖时间而非另起位置；项目行的「新建会话」与菜单按流式依次排开，不再用绝对定位互相覆盖。
- 区域：侧栏头部合并新建会话与筛选；筛选展开为独立一行；项目/会话标签只做分组；术语统一为「会话」；删除不可达的返回对话按钮。
- 停靠栏：页签兼作面板标题，面板不再重复同名 H1；目录范围写成 `1–22 / 22`；统计口径、空目录与文件筛选文案收短。
- 文案：空会话只留标题与动作；欢迎卡去掉重复正文；设置输入框不再逐行提示保存；终端空闲只留工作目录；设置分类不再附带复述内容的说明。
- 呈现：图标按钮三档落地；停靠栏页签选中态与导航一致；文件行与列表行共用圆角；面板头合并为一份实现。
- 布局：窄窗口打开停靠栏先收侧栏并收窄停靠栏；「回到最新」独占一行，不再压住会话流末条消息。
- 清理：删除 12 个无引用的样式类和 126 个无引用文案键，中英字典保持同键。
- 已收口：空状态并为一套；标题层级与弹窗、面板尺寸统一到类型尺度；焦点环归为一套 token；间距与层级补 token；暗色覆盖齐全；死样式与死文案清理。
- 本轮没有已知未收口项。类型尺度目前覆盖标题与外壳间距，正文与面板内部的字色、字号仍留在各组件自己的规则里。

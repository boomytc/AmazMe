# Web 客户端的区域、布局与呈现

本包是 Web 与 Electron 共用的页面。会话、账号与执行状态归 Python Host 所有；这里只决定界面如何承载和呈现它们。窗口原生外观（标题栏、红绿灯、拖拽）归桌面壳，页面画的是同一条 `titlebar`。区域、布局、组件与文案的现行约定如下。

## 区域职责

| 区域 | 尺寸 | 承担 | 不承担 |
| --- | --- | --- | --- |
| `titlebar` 标题栏 | 48px | 当前视图的上下文与动作：标题、运行态势、侧栏开关或管理返回、会话内搜索、分叉、展开停靠栏和审批提醒；桌面壳内同时是窗口标题栏（macOS 红绿灯内嵌、整行可拖拽）。停靠栏打开时这一行只占左侧三列，右端第四列从窗口顶端到底端由停靠栏自己绘制 | 列表操作、全局导航 |
| `app-rail` 应用栏 | 56px | 全局目的地（对话、插件、技能、自动化）、品牌与连接状态、设置入口 | 列表操作、当前会话的上下文 |
| `sidebar` 侧栏 | 268px | 仅对话视图的会话导航：新建会话、筛选、项目与会话分组 | 全局导航；项目编辑在项目行菜单里 |
| 主列会话流 | 余量 | 唯一滚动区：消息、工具过程、审批卡、提问表单 | 固定标题栏与输入区 |
| 主列输入区 | 内容高度 | 草稿、附件、权限、模型、队列与命令面板 | 接管会话流滚动 |
| `dock` 停靠栏 | 视口 45%（300px–70vw） | 当前会话的伴随工具，贴靠窗口右缘的整高面板；面板顶边是页签条（28px 页签胶囊、发丝分隔、条末全屏与收起控件），面板主体紧接条下；需要上下文或动作时显示面板工具行；全屏形态覆盖窗口并保留底层列宽 | 重复页签标题、全局导航 |
| 管理视图 | 主列 | 插件、技能、自动化与设置的整页呈现；此时隐藏侧栏与停靠栏，返回对话在 `titlebar` | 悬浮窗式设置 |
| 浮层 | 视口 | 菜单、选择器、弹窗、命令面板；不改动下层布局 | 常驻状态 |

侧栏只在对话视图出现；进入管理视图后由 `titlebar` 的返回入口回对话。折叠侧栏后，`titlebar` 提供唯一的展开入口，侧栏头部不再重复这个开关。

## 布局规则

- 窗口第一行是 `titlebar` 48px；停靠栏打开时它只占左侧三列，第四列留给停靠栏（默认视口 45%，下限 300px、上限 70vw，主列保底 560px）。桌面最小窗口 1184（`packages/gui/src/main.ts`），更窄的窗口不作为版式目标。
- 停靠栏是从窗口顶端到底端贴靠右缘的整高面板：它的 48px 页签条就是面板顶边，第四列的横向规则从这一条开始，页面不为停靠栏再加第二层头部。收起时整条面板滑出右缘、列宽归零，`titlebar` 跨满整行；收起的面板不占宽度也不留轨条，打开入口只在 `titlebar` 右端。
- `titlebar` 按窗口宽度排布，不随侧栏或停靠栏开合换行；标题单行省略，运行态势放标题下方。页签条与 `titlebar` 共用 48px 中线：28px 页签与工具条按钮（32px）及面板控件（28px）都以这一行的中线对齐。
- 桌面窗口外观由壳决定：macOS 用 `titleBarStyle: hiddenInset` 和固定的红绿灯坐标，页面只在 `:root[data-desktop="darwin"]` 时给 `titlebar` 留出 78px 的交通灯内嵌，并让别的平台与浏览器模式保持普通单行工具条。`titlebar` 是拖拽区，按钮与输入框是 `no-drag`；窗口底色跟随页面 canvas（`amazme:set-window-background`）。
- 窄窗口先让宽度给会话：窗口不足 1280 时打开停靠栏会收起侧栏；CSS 唯一计算宽度上限 `max(300px, min(70vw, 窗口 - 884px))`（侧栏折叠后按 616px 计算），再将偏好宽度限制在 300px 到该上限之间，即停靠栏先降到 300px 下限，把余下宽度让给阅读列。
- 停靠栏宽度由读者决定：拖左缘 8px 隐形抓手或用方向键（16px 步进）调整，双击复位到视口 45%；偏好按浏览器保存在 `localStorage`（`amazme.dock.width`），呈现形态另存为 `amazme.dock.presentation`；开合与重开窗口都保留，窗口变窄只收紧本次渲染宽度、不改写偏好。
- 停靠栏有两种呈现形态：`push`（默认）让会话为面板让出列宽，`fullscreen` 覆盖整个窗口而底层三列宽度不变；切换时面板宽度以 300ms 缓动，macOS 下全屏的页签条按红绿灯宽度内缩起始内边距。窗口低于 768px 的自动全屏规则不在桌面版式范围内。
- 停靠栏只有一套几何计算：`--dock-reveal` 在 0–1 间过渡，第四列宽度为 `--dock-width × --dock-reveal`；push 面板的位置由同一乘积确定。全屏只改变面板宽度，底层轨道仍使用 push 宽度。开合不由 JavaScript 定时器控制；宽度复位与形态切换共用 App 的动画所有者。
- 滚动只发生在五个容器里：`session-list`、`transcript`、管理视图、`dock-scroll`，以及停靠栏页签条自身的横向滚动。标题栏、应用栏、侧栏头部、输入区、停靠栏页签条与面板头固定。
- 会话流与输入区共用一条内容轴：`--column-max: 768px`，由 `center` 的容器宽度决定，而不是窗口宽度。
- 空状态占满主列，标题与输入区的垂直关系固定；空状态最多一句可操作说明，不与输入区占位符说同一件事。内联空状态只有一套排版（`.empty-state` 组），侧栏、面板、连接列表与选择器只保留内边距和对齐差异。
- 标题层级由 `tokens.css` 的类型尺度承担：欢迎页 30/38、欢迎卡 24/32、管理页面 22/30、弹窗 17/24、停靠栏面板 15/20、页签 13、分组 14/22；分区标签 12/500，元信息 12。停靠栏页签已经是标题，面板内不再出现同名 H1。
- 面板头只有一份实现（`react/panel-head.tsx`）：停靠栏与管理页共用标题、描述与动作的排布；标题为空时只渲染其余部分。停靠栏把面板头固定在页签条之下（38px 单行，标题与动作同排，不换行），描述作为内容首行随面板滚动；管理页仍把面板头放在阅读流里。
- 终端标签页只显示交互式屏幕：页签条下方直接是 xterm，shell 结束与未确认输入改由页面提示表达，不再另设命令行输入、提示行或停止控件；关闭标签页就是结束对应 shell。停靠栏不可见时释放终端显示组件，保留后端终端；拖拽在收起、全屏、失去指针捕获或卸载时结束。
- 瞬时提示只有一套呈现：窗口右上角的固定悬浮卡片层，默认 2.5 秒自动消失，相同文案合并为一张、不同文案按新到旧堆叠；指针进入卡片区域时暂停计时，移出后每张卡片重新计时。该层浮在页面上且不占布局高度，提示出现或消失都不推动下方内容。连接状态仍由品牌点的颜色与工具提示表达。
- 停靠栏页签条只有一条，横向溢出时滚动、滚动条隐藏、溢出侧 24px 渐隐，活动页签自动滚入视野；条末的全屏与收起控件在滚动区之外，从不收缩或被裁切。
- 浮层不推动布局；打开菜单、选择器或弹窗时，下层区域不重排。

## 组件规则

- 图标按钮按使用场景分三档：32（标题栏、侧栏头部、面板动作）、28（行内与菜单）、22（紧凑清除），由 `.icon-button` 与 `--compact`、`--mini` 修饰符实现。同一档共用圆角、悬停、展开、禁用与焦点样式，尺寸以外的位置由各组件自己负责。
- 行：会话行 36、面板行 38、项目行 36，统一 `--radius-md`；选中态只用 `--active`。
- 页签：停靠栏 28px 胶囊，16px 图标加 13px 标题；相邻页签之间是 10px 槽位里的 14px 发丝，选中页签两侧的分隔隐去；标题超宽时在末端 16px 淡出而不是画省略号；管理分类沿用 38 的行式导航。
- 选中态统一用 `--active` 底：停靠栏页签、导航行、会话行一致；展开态、悬停态各自用 `--hover`，不叠加卡片阴影。
- 卡片：`--radius-xl` 加发丝线或 `--shadow-card`；浮层用 `--raised`、`--shadow-popover`、`--radius-md`。
- 输入：常规 32、筛选 30、设置字段 40。宽度随栏宽，控件高度不随内容变化。
- 状态色只表达语义：`--danger` 失败、`--warn` 需要注意、`--success` 已连接或已保存；不让 `--diff-add` 兼任状态色。
- 标题栏是一条不可换行的工具条：标题单行省略，状态在标题下方；桌面壳内整行可拖拽，交互控件标记 `no-drag`。
- 焦点环只有一套：`--focus-ring`、`--focus-ring-offset`，被滚动或浮层裁切的行走 `--focus-ring-inset`；字段聚焦是强调边框加 `--focus-shadow`。
- 间距按 `--space-2` 到 `--space-24` 的 2px 尺度；层级按 `--z-brand`、`--z-jump`、`--z-quote`、`--z-combobox`、`--z-tooltip`、`--z-dock`、`--z-popover`、`--z-menu` 命名。
- 停靠栏开合与宽度切换都用 `--dur-slow`（300ms）配 `--ease-in-out`，系统开启减少动效时取消过渡和页签平滑滚动；宽度拖拽和窗口缩放即时更新，不跟随动画。
- 暗色配色覆盖全部随主题变化的 token，包括开关手柄与阴影。

## 文案规则

术语表：

| 概念 | 用词 | 不采用 |
| --- | --- | --- |
| 窗口顶部的一条工具条 | 标题栏 / titlebar | 顶部导航、nav bar |
| 一条持久会话 | 会话 / session | 聊天、对话 |
| 对话界面本身 | 对话 / conversation | 会话（指界面时） |
| 项目根 | 项目 / project | 工作区（内部路径概念才叫工作区） |
| 右侧伴随工具 | 停靠栏 / dock | 会话工具、侧栏 |
| 停靠栏内的一页 | 面板 / panel | 页签 |
| 管理视图 | 管理 / management | 设置（只指设置页） |

- 标题不重复：页签即标题时不再渲染同名标题；分区标签不复述紧邻的按钮或内容。
- 能用布局与组件表达的，不写成句子：计数用 `1–22 / 22`，快捷键进快捷键面板，操作结果由控件状态表达。
- 设置项描述至多一句，不复述 label；教学性长文（cron、时区、统计口径）放 tooltip 或折叠区。
- 占位符是动作短语，`aria-label` 才是完整说明；同一输入的两个属性不写同一串文案。
- 状态文案收成两档：等待你的决定 / 已连接、运行中这类事实。同一事实不在标题栏、面板与统计里各写一套。

# @amazme/web

回环页面。它附着在 `@amazme/coding-agent` 里已经打开的宿主上：宿主负责 HTTP、WebSocket 与启动清单，
这个包只有页面文档与样式、启动契约，以及把宿主复制的状态投影成块的纯逻辑与薄 DOM 渲染器。

- `src/contract.ts`：启动清单（产品名与版本、mode、协议版本、server id、传输 URL，以及宿主读到的语言与外观偏好）与注入标记。
- `src/locale.ts`：页面支持的语言（中／英）、存进设置里的偏好（`auto` 表示随浏览器），以及“偏好优先、否则按浏览器语言匹配”的解析。
  包导出 `./locale`，只含匹配函数，不读 DOM。
- `src/strings.ts`：两种语言的文案字典，全仓只这一份。页面自己的界面文案是平铺的消息键（`zh` 被声明为 `en` 的完整 Record，漏一条就编译不过），
  宿主设置目录的 id、分组 token 与枚举取值则在这里被命名成词；桌面壳的菜单和弹框用 `desktop.*` 键。`localizeDocument` 把宿主送来的静态外壳里的 `{{消息键}}` 标记
  换成本次请求的语言，并写上 `<html lang>`。包导出 `./strings`，同样不读 DOM，Electron 主进程直接 import。
- `src/view.ts`：纯投影，把宿主的 `ConversationView`、名册状态与 `amazme.models` 配置映射成名册项（支持项目分组与旧名册的时间分组）、transcript 块
  （含“是否正在跑”）、新建会话控件与 composer 的模型／推理档选择器，TUI 与网页共用同一份 durable 视图数据，
  只有渲染器不同。
- `src/provider-auth.ts`：把同一模型服务的供应商、登录方式与短期认证提示投影到设置页的供应商账号弹窗；密钥只在密码输入框与一次提交中存在，不写入视图、草稿或会话历史。宿主拥有流程，关闭弹窗后可重新打开继续，显式取消结束登录。
- `src/panels.ts`：管理面的视图模型。面板被描述成“一组行”——标题、可选的值行、控件（开关／下拉／数字／文本）与按钮，
  每个控件与按钮带一个动作 id 和它作用的对象（设置字段、技能名、路径）。这里只做纯映射，渲染器因此不需要知道
  插件、技能、设置的任何业务含义；再加一个管理面就是再多一个纯函数。构建函数接收语言，把宿主发布的身份（字段 id、
  分组 token、枚举取值）翻成读者语言的标签，所以文案只有这一处，宿主不送句子。
- `src/markdown.ts`：助手回答的纯排版单元（标题、列表、强调、链接、围栏代码、表格）与无损代码词法切分（`tokenizeCode`），从不解析 HTML，模型产出的标记
  只会成为文本。表格按分隔行定列对齐，没写对齐的列若整列都是数字则靠右并等宽显示数字，方便纵向比数。
- `src/credentials.ts`、`src/credentials/`：已发送及排队用户文本的公开凭据格式扫描与显示掩码。纯扫描器改编自 DeepSeek Harness（MIT，来源固定为 `571902028a75c64c1d767f4ae5fd099485f0ddf0`），版权和许可随源码及浏览器产物保留。每项可显示/隐藏，换消息或会话后重新隐藏；消息复制按钮使用原文，选区复制使用当前显示字符。原始历史和模型输入不经过掩码，不猜测普通 `password=` 文本。
- `src/render.ts`：只做 DOM，不持有业务状态；跨重建保留展开项、面板与坞的输入草稿、管理分类选择、聊天滚动位置，
  并控制模态框的构建时机，避免重绘吞掉输入。图标都是 `index.html` 里 SVG sprite 的 `<use>` 引用。
- `src/file-browser.ts`：文件面板的面包屑、当前页文件名过滤与只读源码预览组件；仅持有页面级过滤和换行偏好，路径、内容与授权仍由宿主决定。
- `src/theme.ts`：外观偏好（`system`／`light`／`dark`）与 `<html data-theme>` 的对应；文档的启动脚本在首帧前写同一个属性，
  `tokens.css` 的深色配色挂在 `:root[data-theme="dark"]` 上。`system` 时跟随系统且响应系统切换，固定值时忽略系统。
- `src/typography.ts`：正文、代码和终端的全局字体与字号规范，供宿主设置 schema、启动首帧和运行时共同使用；包导出 `./typography`。设置保存在 `settings.json` 的 `typography`，跨标签页同步，默认字号为 15／13／12px，菜单和元数据保持原尺寸。仅桌面端的 Cmd/Ctrl +、-、0 同时调整或重置三种字号，重置保留字体；普通浏览器继续使用原生页面缩放。
- `src/assets.ts`：宿主用来定位页面目录、文档与静态资源（仅供 Node 侧，浏览器入口不引用它）。
- `src/startup.ts`：宿主在入口之前注入的轻量失败兜底。`/page.js` 加载或执行失败时显示本地化诊断和手动重载，
  不清理会话数据、不自动重载；入口正常加载后撤销监听，不接管应用运行期错误。
- `src/page/`：页面静态资源。`index.html` 是文档骨架（启动清单注入在 `<!--amazme-boot-->` 处，SVG sprite 放在 `<body>` 开头），
  `tokens.css` 是页面自己的设计令牌（配色、圆角、字体、动效与投影，浅色一套，`:root[data-theme="dark"]` 深色一套），
  `page.css` 是用这些令牌拼出的外壳与组件样式。

## 设计来源

界面的版式与交互参照三个成熟的对话产品：Claude 的对话栏与设置面板、ChatGPT 的侧栏分组与输入框、Grok 的深色优先与留白。
这里取的是它们的做法，不是它们的品牌。

- 对话列居中，最宽约 768px。助手回答是正文，不套气泡；用户消息是右侧的浅色气泡。
- 输入框是一张圆角卡片：附件、模型与推理档、发送都在卡片里。空会话时问候语与输入框在主区中部成组。
- 最左侧独立导航栏切换聊天与管理页面。聊天侧栏按“项目 → 会话”分组，提供新建会话入口；会话行的更多菜单管理改名、归档与删除。
- 回答下面的操作（复制、评分）悬停或聚焦时出现；连续工具调用与思考合成默认收起的执行过程，显示状态和计数，运行中显示当前动作。失败摘要与中断提示不隐藏；展开后保留原顺序，参数和输出可分别复制，组旁可跳到后续答复。用户展开选择跨刷新保留，切换对话后重置。
- 1023px 以下侧栏与坞变成从边缘滑出的抽屉，点遮罩即收起。

色彩只用中性灰阶加一个强调色：主按钮是墨色圆钮，浅色为黑、深色为白；强调色只用于链接、焦点环和选中标记。
图标是同一套 1.75 线宽的线性图标，放在 `index.html` 的 SVG sprite 里。

有意保留的差异（页面没有对应的宿主能力或素材）：

- 界面文案与它的语言：页面与宿主发布的数据分家——宿主只送设置字段的 id、分组 token、枚举取值等身份，词句在
  `src/strings.ts` 的两份字典里，和 TUI 设置选择器各自持有自己的英文文案是同一个做法。宿主的诊断信息（技能加载器、
  `mcp.json` 校验、设置文件解析）保持宿主自己写的语言，不随界面语言变化；TUI 也仍是英文；全局 `locale` 同时用于网页以及桌面壳的菜单和错误框。
- 代码块采用纯文本词法切分实现轻量语法高亮、伪元素行号与超长代码折叠（超过 24 行默认收起），不引入外部高亮运行时或 HTML 注入，选区与复制仍只包含代码原文。
- 工具结果只有一种卡片形态：工具名、参数摘要与结果统一用同一张卡片，transcript 里没有单独的终端式块。
- 管理面有独立的分类侧栏与主区内容，切换页面不会释放当前会话；设置编辑后留在原页面。设置页的分类栏在宽窗保持展开，不提供折叠；侧栏顶部可搜索设置项，并跳到对应分类里的那一项；Cmd/Ctrl+F 聚焦搜索，窄窗时先展开分类抽屉。
  会话范围的文件、终端、对话、任务和本轮变更位于聊天主区右侧的坞里。管理页面不与聊天并排显示。
- 标志沿用终端界面的像素 AM（`components/am-logo.ts`）：10×4 的像素网格，A 为珊瑚色、M 为黄色，直接落在界面上，不加底块或边框，字母高度与品牌字样的大写高度相当。
  浅色主题下两个字母取加深的同色系，保证对比度不低于 3:1；深色主题保留终端的原色。两个字母是两个 sprite 符号，颜色由类名给出；
  品牌字样与界面字体都用系统字体。

## 文件浏览

右侧文件坞采用紧凑整行点击列表：目录与文件使用不同图标，大小靠右并使用等宽数位；面包屑的祖先可返回，当前路径不伪装成可点击项。文件名过滤仅作用于当前页，刷新保留文字，换目录、页码、工作目录或会话重置；父目录入口不参与过滤。方向键在可见条目之间移动，Escape 清除过滤。

文本预览提供行号、完整路径复制、已显示内容复制与长行换行。沿用宿主的 256 KiB 读取上限，页面额外限制 2000 行 DOM 并明确提示；复制不夹带行号，也不声称包含未显示部分。导航请求保留旧内容、禁用竞争导航并显示读取状态，失败就地提示，换会话后旧请求不回写新面板。导航按已显示工作目录绑定绝对路径，授权与符号链接边界不变。

## 对齐与排版规则

页面按 LightUI 的“对齐”准则检查过一遍，落到样式里的几条：

- 盒子要装得下：`page.css` 开头的全局 `[hidden] { display: none !important }` 让隐藏的坞、附件条、审批区不再占着栅格轨道或边距；
  作者样式里的 `display` 不会再盖过它。
- 窄窗只有一列：1023px 以下 `body` 的栅格退回一列，侧栏与坞改为 `position: fixed` 的抽屉；宽窗时 `body.sidebar-collapsed` 与
  `body.dock-open` 各自增减一条轨道，两者的媒体查询都要覆盖。设置页（`body.settings-open`）在宽窗保持分类栏，折叠规则不覆盖它。
- 头部的动作是图标按钮，标签只留在 `title` 与 `aria-label` 里；640px 以下通道行与 token 数字收起，把宽度让给会话标题。
- 数字成列就等宽：名册年龄、附件大小与表格里的数字列用 `tabular-nums`，表格里整列都是数字的列靠右。
- 会话选择与更多菜单是并列按钮，名称、年龄与操作各自占位，不嵌套交互控件。

这个包不打开会话存储、不执行工具、也不调用模型；这些都在宿主里。浏览器侧入口在
`packages/coding-agent/src/host/web/page.ts`，它绑定宿主的服务（会话范围的 transcript、agent-controller、models、
session-settings、commands、workspace、terminal、conversations、approvals，以及服务端范围的 settings、skills、plugins、
feedback、schedules），驱动 composer、侧栏的新建会话、模型／推理档切换，以及宿主实际发布的管理面板动作。

## 运行控制、图片与会话面

- 运行控制：header 上的“压缩上下文”按钮打开一个可选填指令的模态框，提交走 `AgentController.compact()`；队列每条输入自带“撤回”，按 inbox submission id 调 `cancelQueued`；回合运行中 composer 出现“介入／排队”切换，提交即 `steer()` 或 `followUp()`；“设置 → 模型与连接”提供“刷新模型”与宿主回报的刷新状态。这些控件都是 `actions.ts` 里的动作 id，经与面板同一条 `command` 分发路径回到页面入口。
- 图片：composer 的附件按钮、粘贴与拖放都能加图，附件条给每张图缩略图、名字、大小与自己的移除控件；发送时按 `AgentPromptImage` 走真实 prompt 路径，durable 条目因此带上图片，transcript 里渲染成图片。页面按 PNG／JPEG／WebP／GIF 且 ≤8 MB 校验，不合格的选中项会给出原因而不是被静默丢弃。
- 跨端会话：名册除了宿主自己的会话，还列出宿主工作目录下的终端会话（行上标“终端”），来源由
  `amazme.session-directory` 的 `source` 字段给出；附着一条终端会话即「认领」它——宿主以同一 id 建档，
  用它的 JSONL 里的事件种入 transcript（用户消息、回答、工具结果照搬；会话的模型、推理档与标签不携带，
  由宿主自己的设置决定），此后把每个已提交的版本写回同一个文件，终端那边因此看到同一会话的后续内容。
  投影无法携带的条目按名字计数并记进宿主日志，不静默丢弃。
- 会话面：当前宿主按“项目 → 会话”分组，项目内新会话在前；旧的无项目名册仍可按时间分组。每行显示会话名与年龄，工作目录放在提示中；更多菜单提供改名、归档、复制 ID 与确认删除。归档前提示会停止工作并保留历史。过滤框按名字、ID、工作目录及项目匹配，并区分空列表与没有匹配。切换管理页面保留当前会话、composer 草稿、过滤文字和聊天滚动位置；新建会话返回聊天。聊天头部显示上下文占用百分比、token（已用 / 窗口）和费用，阈值与 TUI 顶栏一致（超过 70% 加重、超过 90% 标红）。
- 连接抖动：附着与首次绘制都不会因为一次连接／附着重绑定把页面变成不可启动——附着失败会在连接行给出原因，绘制异常也在那里报告，页面继续可用。
- 宿主断开与重连：连接断开时连接行写明原因并进入重试（`connection.retrying`），页面记住当前会话，按退避重试
  `client.reconnect()`，连上后先同步最新项目与会话目录，再重新附着仍可用的原会话；同步期间隐藏旧列表。
  断线期间新归档、删除或因项目移除而归档的会话不会自动附着；原本正在查看的归档会话可继续恢复，恢复为活动会话后同步回所属项目。
  重试用尽则如实报 `page.attachFailed`。宿主中断的回合由
  宿主的 durable 运行时恢复，期间会话保持忙碌，新输入被拒绝并给出原因，而不是静默排队。

## 会话工具坞（文件、终端、会话与任务）

主区右侧的坞（头部的“会话工具”图标开关；1023px 以下它是从右侧滑出的抽屉，点遮罩即收起）提供文件、终端、对话与任务；运行控制服务可用时另有“本轮变更”：

- Files：宿主 `amazme.workspace` 的投影，可切换项目源文件夹。目录项打开、文件项读取、`Up` 回上一层；
  目录每页最多 100 项，上一页／下一页由宿主分页元数据决定。重新读取和读文件后返回同一目录保留当前页，
  切换目录回到第一页；目录缩小时自动收敛到有效页。名称仍需完整枚举，但只读取当前页的元数据、复制和渲染当前页，
  不宣称目录枚举本身已成为常量开销。旧宿主未发布分页元数据时不显示翻页控件；
  文本文件超出上限时标出“只显示开头”，二进制与已消失文件各有提示。相对路径从当前选中的源文件夹解析，
  绝对路径可切换到另一个授权源文件夹；规范路径与符号链接目标必须落在项目源文件夹内。
- Terminal：宿主 `amazme.terminal` 的投影。一行命令（Run／Stop），输出以受限缓冲流式进入状态，
  运行中可停止；状态行显示运行命令、退出码或取消结果。终端使用会话执行目录、配置的命令前缀，
  与 Agent 共享执行环境及文件写入隔离，不另建一套执行器。
- Conversations：宿主 `amazme.conversations` 的投影。列出会话里的每个对话——主线标 `main`，子代理的子会话标出「由哪条 task 在哪条会话里创建」，当前聚焦的一条标 `selected`；点「打开」把主区切到那条对话。根对话仍用 Transcript 的实时视图，其他对话由服务发布一份（250ms 合并的）聚焦视图，宿主的 commit 流合并更新列表标签、运行状态和排队数量。人工分叉的更多菜单提供重命名与确认归档，主线和任务拥有的子代理对话不提供这类管理操作。已归档分叉及其拥有的子对话留在同一面板的「已归档分叉」区，可查看历史；人工分叉可恢复，不混入全局会话归档列表。
- 分叉归档：只停止该分叉及按任务归属拥有的工作（包括后台子任务），清空其排队输入及尚未落盘的排队写入；不会沿分叉历史来源连带停止主线或其他人工分叉，也不停止会话级共享终端。恢复保留名称和历史，不重放取消任务。名称与归档状态按对话编号写入同一 SQLite 的 `amazme.forks` 会话文档，不随新分叉继承；请求入口与模型、工具运行钩子共同拒绝归档范围的新工作，重启清理未完成的取消。分叉共享项目文件，没有文件回滚、硬删除或合并操作。
- Tasks：同一服务的实时任务图，用可读名称显示任务种类、编号、阶段、状态及等待和所属关系。“查看对话”与“查看子对话”切换焦点，不重新启动任务。
- 本轮变更：宿主 `amazme.session-insights` 的投影，提供文件列表、只读 diff、验证命令结果及预算暂停后的继续入口。归因与容量限制见[运行控制](../coding-agent/docs/run-controls.md)。
- 历史分页：先以当前 transcript 最旧的条目为上界探测一条历史记录，确认存在更早记录后才在顶部显示「加载更早」；没有记录或尚未确认时不显示。探测不把记录加入页面，切换会话、对话或当前条目的上界变化时重新确认。第一页以当前 transcript 最旧的条目为上界（`maxEntryId`），所以翻出来的内容一定在已显示内容之下、不会重复；之后按游标继续往回（每页 20 条，游标用完即止）。翻出来的条目按与实时 transcript 相同的投影排在 `.history-pages` 里，读法一致。
- 坞的输入行在重绘时复用同一个 DOM 节点，正在敲的命令与焦点不会被下方到来的输出冲掉。
- 会话 worker 现在也装上了 `subagent` 工具（TUI 的 durable runtime 一直有），所以网页里的一次真实运行可以派生子会话，并在列表与任务图里被正确归属。

## 工具审批

设置里的「权限与确认 → 工具确认」有三档：`off`（直接运行）、`dangerous`（bash／powershell／write／edit 前询问）、
`all`（每次调用都询问）。会话 worker 在 Harness 打开前把 `beforeTool` 钩子装进自己的 registry（worker 的
approvals facet 提供 `amazme.approvals` 的状态）：命中策略的调用会被发布成一条待批请求（工具名、参数摘要、
task 与会话 id），钩子在那里等；页面在 composer 上方给出卡片，「通过」让调用照常运行，「拒绝」把这次调用
结算成失败的工具结果（`Denied by the reader: …`），回合继续往下走。这是工具边界上最小的一段暂停／恢复，
没有额外的策略引擎；回合被中止时待批请求按拒绝结算。`state` 是远程服务成员，所以服务对象上的 `state`
必须是数据属性而不是 getter。

## 命令、快捷键与复制

- 输入框 `/` 列出技能、提示模板和插件动作，支持前缀搜索与插件参数补全。插件走 `Commands.run`，模板和技能走 `Commands.expand`，由页面发送到当前对话。未知命令会明确拒绝，不进入模型输入。新增模板通过“设置 → 配置与诊断 → 重新加载会话资源”读取。
- 模型与思考强度：输入框右下使用两个原生下拉框，模型选项仅来自 `scoped_models`，思考档位随当前模型能力变化；变更只影响当前对话的后续请求。设置页提供相同下拉框，调整后留在设置页，可显式“设为新会话默认”。
- 模型列表：设置页打开可搜索的复选列表，控制模型下拉框和轮换的候选项。全选包含之后新增的模型；清空保留空列表。隐藏当前模型不会切换它，也不会把它重新加入候选项。默认仅应用于当前会话，勾选“新会话使用相同模型列表”才写入 `enabledModels`。
- 供应商账号、压缩、会话改名与分叉均通过点击操作；终端 `/model`、`/thinking`、`/scoped_models`、`/login` 不作为网页输入框的设置命令。
- 快捷键：`shortcuts.ts` 是一张表，同时用于读者可见的说明和按键匹配。产品键沿用 DSH 网页端的约定
  （`primary`＋Alt：⌘⌥N 新建会话、⌘⌥M 轮换管理视图）；`/` 在不处于输入框时聚焦 composer。停止回合是一次
  Ctrl+C（对标 TUI；有选区时仍是复制），composer 里同时有一颗只在回合进行中出现的停止按钮，草稿非空时它也不让位给发送。
  `Escape` 关闭菜单、模态框或侧栏抽屉；回合进行中它把焦点指到停止按钮，不取消回合。
- 复制：围栏代码块的 banner 上带复制控件，写进剪贴板的就是代码本身；每条助手回答的操作行里也有复制，写进剪贴板的是回答原文。成功与失败都在控件上显示。

## 交互状态：进行中、失败与焦点

管理面的一次调用有它自己的状态，页面对此只有一处描述：`panels.ts` 的 `PanelSpec.pending` 与
`PanelModal.pending`／`notice`。页面把「正在进行的动作（动作 id + 对象）」和「它上一次说的话」交给
`panelView`，纯层把进行中的那个控件标成 busy（渲染器据此禁用并加 `.pending`），把消息排在面板通知之前、
或放进模态框卡片里自己的一行。因此：

- 面板行按钮或模态框提交在调用进行中会变灰并拒绝第二次点击；成功后回到常态，面板按宿主发布的新状态重绘。
- 调用被拒或失败时，原因出现在**发起它的那个控件旁边**（面板的 `.panel-notice.error` 或模态框的
  `.modal-notice.error`），模态框保持打开并保留已输入的内容，成功后再关闭。
- 用 Esc 或关闭控件关掉模态框时，焦点回到打开它的那个控件（按动作 id + 对象重新查找，因为重绘会换掉节点）。
- 这些调用都经过与附着同样的重绑定重试：删除当前附着的会话本身会释放本连接的附着，调用因此在其后发出并在
  绑定被替换时重试一次。

组件状态一律取自 token：悬停用 `--hover`，选中用 `--active`，输入类边框用 `--line-strong`，主按钮用 `--ink`；
`:focus-visible` 的 2px 强调色轮廓由 `page.css` 的全局规则给出，`page.css` 不写颜色字面量。

## 消息反馈与首启引导

- 消息反馈：每条已提交的助手回答下面有一排操作：复制（写进剪贴板的是回答原文），以及一对拇指控件（`feedback:up`／`feedback:down`，`data` 是条目 id）。
  这一排平时隐藏，悬停或聚焦回答时出现，触屏上常驻；已评分的那个拇指保持按下的样子。
  评分存在宿主 agent 目录的 `feedback.json`（服务端范围的 `amazme.feedback`），CLI 也能读到同一份文件；
  同一条回答再评一次是替换而不是追加，再点同一个拇指是撤回。评分控件只在“这条回答存在且已结算”时出现，
  正在流式输出的回合没有评分控件；没有反馈服务时只剩复制。
- 空会话：没有任何条目时，主区中部是问候语与输入框，两者成组居中。没有附加会话时，问候语指向侧栏里的会话（名册非空），
  或给出“新建会话”（名册为空）。
- 首启引导：宿主的会话名册为空（且已连上、有工作目录）时，主区显示一张欢迎卡片：三步入口（新建会话、
  打开文件与终端、看看设置）各带一个动作，以及“不再显示”。“不再显示”把 `showWelcome` 写成 `false`
  （写进 agent 的 `settings.json`），之后不再出现；在设置面板的「界面 → 欢迎引导」里可以重新打开。

## 可选自动化

只有宿主选择[自动化插件](../coding-agent/plugins/automation/README.md)并重启后，导航才显示 Automation；未选择时不读取计划或启动定时器。页面投影服务端的 `amazme.schedules`，不负责执行计划。

- 支持固定间隔（正整数分钟）、指定时区的一次性时间与五字段 cron；可配置忙碌时排队或跳过、错过时刻的处理、宽限及超时。
- 计划固定目标会话和对话，切换焦点不会重定向。行上提供立即运行、编辑、暂停／启用、取消当前运行、最近二十次记录及确认删除。
- 默认每 5 秒检查时间，同一计划不重叠，宿主最多持有四个运行；等待模型不占时间检查或文件变更队列。回答写入目标对话，页面关闭后仍由宿主持有。
- `<agentDir>/schedules.json` 持久保存计划、投递编号和待结算状态；重启恢复原投递，不另发一份输入。旧版、损坏或外部变化的文件进入只读，保留原文，修复后再重新读取。
- 暂停只停止未来触发，仍可手动运行；取消与删除按原编号等待清理，不取消其他用户输入。归档会话拒绝投递。详细时区、恢复及文件租约规则见插件文档。

## 语言与外观

界面语言（中／英）与外观（浅色／深色／跟随系统）是两个存在 agent 的 `settings.json` 里的偏好
（`locale`：`auto`／`zh`／`en`，`appearance`：`system`／`light`／`dark`），在管理面板的第一组“界面”里改，
和 CLI、TUI 共用同一份设置文件，所以换台浏览器也一样。页面与面板按“偏好优先，否则按 `navigator.languages`
匹配，都不匹配就用英文”解析语言；`auto` 就是交给浏览器。

宿主在每次响应文档时读一遍这两个偏好（它自己开一个 `SettingsManager`，读的是同一份文件），把偏好写进启动清单，
并按 `Accept-Language` 解析语言后本地化静态外壳：侧栏文案、空状态、按钮的 aria 标签在 HTML 到达时就已是该语言，
首帧不会闪英文，`<html lang>` 也正确。外观偏好同样写进清单，文档头部的调色板脚本按它决定首帧是浅色还是深色
（`system` 才看 `prefers-color-scheme`），页面随后用同一份偏好继续跟随设置变化。在面板里切换语言或外观时，
页面不需要刷新：写进设置后经复制的设置状态回到页面，重绘即换语言、换调色板。

## 管理面

侧栏按“项目 → 会话”导航。创建和编辑项目时选择多个源文件夹，Web 在宿主电脑上浏览目录，桌面使用原生文件夹选择器。项目行的选项菜单管理名称和文件夹，右侧按钮在该项目中新建会话。第一个文件夹作为新会话的默认执行目录；已有会话保留原执行目录，项目设置、MCP、AGENTS.md 与记忆据此读取。所选文件夹保存项目信任并传给 Agent，文件面板可在其中切换，工具操作沿用现有审批设置。空项目保留，旧的单目录项目自动兼容。项目注册存放在宿主会话目录的 `.projects.json`，会话元数据记录 `projectId`；旧会话补存项目归属，编辑目录前也会保存尚未打开的终端会话归属，避免它们被重新分组或漏归档。

保存项目文件夹后，各窗口刷新当前会话的项目信任、配置和 MCP；再次保存相同目录也会同步授权，执行目录仍保留。

运行中的任务在每次工具调用前重读审批设置和项目信任，不依赖客户端附加。移除项目后不再发布其工作区，恢复所属会话后重新采用当前项目目录；归档统一停止运行任务、后台子任务、排队输入和终端命令，并拒绝新工作；历史与文件修改保留，执行目录不变。归档会话只读，恢复后才允许再次执行，已取消的任务不会自动重放。旧归档记录也按只读和停止工作规则处理。

重连或重启客户端时，先核对最新项目和归档状态，再刷新工作区、信任与配置后开放会话操作。宿主重启保留已有项目目录选择，不重新添加已移除的源文件夹；新的终端会话仍按启动目录注册项目。

会话菜单只提供统一的归档及恢复。全量归档会话在“设置 → 已归档”集中管理，可打开历史或恢复；聊天侧栏只固定当前正在查看的归档会话，不提供归档列表切换。移除项目会归档其中所有会话并停止工作，保留历史和目录文件。恢复会话会重新显示所属项目。归档状态保存在会话元数据的 `archivedAt` 中；对 JSONL 终端会话，宿主另写独立的 `.jsonl.archived` 标记，原始 JSONL 历史不被改写。各继续入口读取不同的存储：

- JSONL 模式的继续会话和 SDK 终端的 `/resume` 根据 `.jsonl.archived` 标记跳过归档会话。
- 默认终端的 `amazme --continue` 选择当前工作目录下最新的 Durable 会话目录，不读取 `.jsonl.archived` 标记。
- `amazme client --continue` 根据会话元数据中的 `archivedAt` 跳过归档会话，不靠 JSONL 标记筛选。

项目与当前会话（包括正在查看的归档）作为同一份选择在本标签页刷新后保留；宿主会话目录的 `.selection.json` 原子保存最近选择，供桌面重开或 Web 地址端口变化后的新窗口恢复。恢复时重新核对当前目录和归档状态，不自动打开离线期间新归档的会话，也不把明确未选会话的项目切到其他会话。

同一宿主的 Web 标签页和桌面窗口共享项目、会话列表，各自保留当前选择。在线时其他窗口归档当前会话或移除其项目，本窗口继续只读查看并在侧栏固定该归档；会话被删除时清空会话。正在查看的归档会话被恢复时，同步回所属项目。新建会话只保留侧栏入口，使用上次选中的项目，启动仍恢复原会话。

最左侧导航栏切换聊天与宿主提供的 Plugins、Skills、Automation，底部入口打开 Settings。管理页面的侧栏列出分类，主区只显示所选分类；设置默认打开“界面”，之后保留分类选择。插件、技能和设置页不再重复页头标题和返回按钮，切换靠左侧导航。自动化仍可用返回箭头或左侧导航回到原会话。回到原会话不重新附着，草稿与聊天滚动位置保留。模型和思考档位的设置也留在当前页面。
设置里的“已归档”分类列出所有归档会话及所属项目、归档时间和到期提醒，包括已移除项目中的会话。“打开”返回聊天只读查看；“恢复会话”回到所属项目并清空旧的侧栏过滤条件，避免恢复后的会话被隐藏。打开归档后可通过会话菜单确认删除。保留天数仅用于提醒，不自动删除。
面板的行、控件与按钮全部来自 `src/panels.ts` 的纯映射，动作只是 id 加对象，由入口解释成宿主调用。

- Plugins：插件包（宿主按 server 默认选择构建并写入 server profile，对之后打开的会话生效）与 MCP 服务器
  （全局 `mcp.json` 的增删，以及已附加会话实际配置的启停、exposure、连接状态、重连与登录）。服务列表与错误跟随当前会话，避免混入宿主目录的项目配置；全局服务可通过「仅在此项目设置」写入当前会话可信项目的覆盖配置。
- Skills：宿主自己加载的技能清单；agent 目录下的技能可新建、编辑、删除、导入，项目与配置路径里的技能只读展示。
  修改与重新读取会刷新宿主目录，并请求当前会话刷新资源命令；新会话加载当前文件，新的模板或会话插件变更通过“设置 → 配置与诊断 → 重新加载会话资源”读取。
- Settings：当前会话发布有效字段目录（未附加时使用宿主目录），包括分组、类型、枚举取值和是否由文件显式设置；
  标签与说明由页面按 id 给出，未知字段回落到 id；默认分类“界面”包含语言与外观。改动写进全局 `settings.json`；面板同时列出文件路径与
  解析错误；“配置与诊断”分类提供“重新加载设置”“重新加载会话资源”和“查看诊断报告”。数字控件在本地按宿主的范围校验（超范围的草稿留在输入框里并标出，不发出请求），
  其余校验仍由宿主负责。设置写入全局文件，项目覆盖继续优先；界面显示当前会话实际采用的值与文件路径。写入、重新读取及再次附加会话时会重读设置，MCP 也在再次附加时重读其配置。
- Automation：可选插件提供的计划任务（见上）。新建与编辑按所选时间规则显示字段；页面检查非空提示与正整数间隔，宿主继续校验规则、时区和执行策略。未附加会话时“新建”不可用，面板说明原因。

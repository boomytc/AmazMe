# @amazme/web

本机回环页面。它附着在已经打开的宿主 socket 上，列出会话，打开一段转录，提交提示，并在回合结束前显示助手文本和工具状态。提示框里的斜杠命令和全屏用同一套 `parseSlash`。命令结果显示在转录下面。`/quit` 不停止宿主。登录回调由打开页面的进程提供；没有回调时，`/login` 只说明当前页面不能登录。

监听地址只有 `127.0.0.1`。这个包不打开 JSONL，不执行工具，也不调用模型。宿主在 `@amazme/coding-agent`。

这是 AmazMe 第一个大版本的网页客户端。没有版本 1 标头的会话或 runtime 文件由宿主拒绝，页面不会迁移它们。

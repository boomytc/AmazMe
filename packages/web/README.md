# @amazme/web

Web 和 Electron 共用的 React 19 + TypeScript 页面：导航、聊天、模型连接、管理面板和会话停靠栏。会话、账号与执行状态归 Python Host 所有；本包保留草稿、界面偏好和按宿主/会话绑定的未确认操作编号，不加载旧 Durable 运行时。

窗口顶部只有一条 48px `titlebar`：标题、运行态势、侧栏开关或管理返回、会话内搜索、分叉、展开停靠栏和审批提醒都在这一行。停靠栏是贴靠窗口右缘的整高面板（列宽默认视口 45%，300px 起、最多 70vw），面板顶边就是它自己的 48px 页签条：28px 页签胶囊、发丝分隔、条末的全屏与收起控件；面板主体紧接条下，仅在有上下文或操作时保留工具行，不重复页签标题。`push` 形态让会话为面板让出列宽，`fullscreen` 覆盖整个窗口而底层列宽不变；收起后整条面板滑出右缘、不占宽度，唯一入口是标题栏右端的展开按钮。开合与全屏共用一条 300ms 曲线并遵守系统减少动效设置；打开时焦点落到当前页签，收起时回到展开按钮。宽度可拖左缘 8px 隐形抓手或用方向键（16px 步进）调整、双击复位，宽度与呈现形态都按浏览器记住（`amazme.dock.width`、`amazme.dock.presentation`）；`⌘⌥Enter` / `Ctrl+Alt+Enter` 在面板可见时切换全屏。桌面壳在 macOS 上以 `hiddenInset` 隐藏原生标题栏，页面通过 `window.amazmeDesktop` 的 `platform` 在 `:root[data-desktop="darwin"]` 预留红绿灯内嵌并把整行作为拖拽区；浏览器或 Windows/Linux 下同一行退化为普通工具条，停靠栏页签条同样是窗口拖拽区，全屏时按红绿灯宽度内缩。窗口原生外观归 `@amazme/gui`，页面不探测 Electron 版本。

停靠栏按需打开标签：初始显示工具入口页，点 `+` 打开新标签页，选择工具后替换入口页；已有工具只定位一次，不重复创建。标签可独立关闭，关闭当前标签选中相邻标签，关闭最后一个工具标签收起停靠栏，下次展开回到入口页。左右方向键及 Home/End 移动标签焦点，Enter/Space 选择，Delete 关闭。标签集合与当前选择按 profile/会话保存在本窗口的 `sessionStorage`，刷新和切换会话可恢复。终端标签页直接显示可交互的 shell，不再另设命令行输入；关闭终端标签只关闭显示，正在运行的 shell 保留，再次打开仍连接它，终止 shell 使用终端页的「停止」。

动作失败、连接诊断和 shell 结束这类瞬时提示统一显示在窗口右上角的悬浮卡片层：默认 2.5 秒后消失，多条按新到旧堆叠，相同文案只保留一张；指针移到卡片区域时暂停计时，移开后重新计时。该层浮在页面上、不占布局高度，提示的出现和消失都不会推动或重排页面。

`npm run build --workspace @amazme/web` 生成 `dist/page`。Python Host 在源码模式读取该目录，冻结包将同一目录装入资源；`npm run dev:web` 会先构建客户端。HTTP/事件类型及运行时校验由 `backend/tools/export_contracts.py` 从 Python 生成到 `src/generated/`（`contracts.ts`、`schema.json`），`--check` 检查漂移。

正式页面由 React 接管，继续复用现有 CSS、主题和文案。唯一浏览器构建链路是 `build-page.mjs` 的 esbuild；TSX 同时进入 TypeScript 检查，生产 bundle 使用 React 的 production 构建。`dist` 还包含公开 TypeScript 包导出；`./locale`、`./strings`、`./typography` 和 `./errors` 是无 React/DOM 副作用的轻量入口，Electron 主进程只使用这些入口。

公共控件采用同一套灰阶、圆角、聚焦和按压状态。密码框参考 [OpenSourceUI](https://opensourceui.in/components/password-field-input) 的行内眼睛控件，输入、按钮和浮层参考 [EasyUI](https://easyui.site/docs/introduction) 的组件模式，映射到现有 `tokens.css` 和 CSS；Lucide 提供标准 Eye/EyeOff 图标。供应商搜索选择使用 Base UI Combobox 处理键盘、焦点、定位和列表语义，浮层挂入所属原生 dialog，供应商 ID 仍由 Host 目录提供。来源与许可随 [页面资产](src/page/third-party-notices.txt) 打包。

`src/page.ts` 为每个窗口创建 `PageRuntime` 和 React `Presentation`。运行实例拥有 PythonClient、导航、待确认账本及页面释放；`app/` 中的草稿、历史、设置、供应商、集成、自动化和工作区模块分别拥有对应状态。页面启动在 React 生命周期之外，普通重挂载不会重新连接或写入。运行实例销毁是终态，关闭页面会使导航续体失效。

`react/state.ts` 将缓存投影通过 `useSyncExternalStore` 提供给各呈现区域；一次发布先更新所有区域的快照，再通知订阅者。渲染和订阅不发命令。聊天、输入、问题表单、管理面板、Markdown 与停靠栏均为 React 组件，xterm 只拥有独立容器内部。显示组件释放不会停止后端 PTY。

`render.ts` 只保留页面入口与 React 呈现之间的 `PageRenderer` 契约；页面运行时由 `src/page.ts` 唯一创建并挂载 React，不再保留第二套 DOM 渲染入口。同一容器只允许一个 root，原协议消费、生成契约、账本与纯视图转换继续复用。

区域职责、布局与文案规则见 [ARCHITECTURE.md](ARCHITECTURE.md)。现行契约见 [Python 方案](../../docs/python-backend-plan.md)。

回答中的本地 Markdown 链接可打开文件停靠栏，如 `[源码](src/main.py:42)`、`[源码](src/main.py:42:9)` 或 `[源码](src/main.py#L42-L45)`。列号和范围定位到起始行；相对路径以会话工作区为基准，绝对路径必须属于当前项目的工作区。文件名里的字面冒号、井号用 `%3A`、`%23` 转义，含空格的目标可写成 `<src/a file.py:42>`。

行定位按需读取最多 1 MiB 的前缀，显示目标附近最多 2000 行；超出范围时明确提示。分页间版本变化会停止预览，切换会话或关闭文件面板后不再接收旧读取结果。HTTP(S) 裸链接自动识别，中文标点和 Unicode 符号保留在链接外，Unicode 字母仍可用于路径；行内代码和代码块保持原文。

文件预览内容不变时保留现有 DOM；重新读取保留原行范围、可见行与横向位置，关闭再打开停靠栏也恢复位置。位置按 Host、会话和文件隔离，页内最多记住 32 份，不写入用户会话数据。明确点击新的行链接时以新目标为准。

模型提出结构化问题后，输入区上方显示待答表单。单选预选第一个推荐项，多选预选全部推荐项；每题都可补充文字。预选不发送数据，必须点击「提交回答」或「跳过」。表单草稿跨普通渲染保留，切换会话时按原会话隔离；答案绑定具体问题、摘要和代次，通过已有写入账本保留原操作编号。

自动化面板可创建独立任务，选择每次新建会话，指定工作区、任务名和模型；也可继续已有会话。任务操作绑定 Host，创建时不要求已打开会话。运行记录保留每次实际目标，行菜单可打开最近运行的会话；编辑名称、内容或目标时保留未改动的触发时间。

执行过程中的 `apply_patch`、`write_file`、`edit_file` 显示后端保存的实际差异。部分失败时分别列出完成、失败和跳过项，只为已完成项显示 diff。工具输出与原始回执分别阅读，原始回执可展开复制。差异总量最多 16000 字节，截断会明确提示；未知执行结果不会由请求参数生成差异。

`/diff` 或 `/diff uncommitted` 只读比较工作区与 HEAD；`/diff unstaged` 比较工作区与暂存区，二者都包含未跟踪文件。`/diff staged` 只比较暂存区与 HEAD。模型可调用同一 `git_diff`，并用 `path` 选择已授权工作区内的仓库。没有提交的仓库使用空树为基准；结果保存分支、HEAD、文件状态、重命名来源和最多 32000 字节的差异。文件清单最多 200 项且总量受限，截断和未读取的文件明确标为不完整。它不 fetch、不暂存、不提交，也不提供后续写文件的读取基线。Web 将其标为只读审阅，原始回执仍可展开。

点击输入区的用量指标，或打开会话工具中的「统计」页，查看完整会话、按模型和最近 100 回合的统计。缓存命中率按 token 加权，费用沿用调用时保存的目录价格，压缩按原调用去重。耗时显示实际测量覆盖，旧记录缺项保留未知。自动刷新和手动刷新共用带请求代次的读取入口，迟到响应不会覆盖后发请求的结果。

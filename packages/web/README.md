# @amazme/web

本机回环页面。它附着在已经打开的宿主 socket 上。用户消息、助手的标题和代码块、工具标题是分开的块。底栏有工作目录、会话、模型和忙闲。`/model`、`/thinking`、`/resume` 不带参数时在输入框上方列出可选项。`/quit` 不停止宿主。登录回调由打开页面的进程提供；没有回调时，`/login` 只说明当前页面不能登录。

监听地址只有 `127.0.0.1`。这个包不打开 JSONL，不执行工具，也不调用模型。宿主在 `@amazme/coding-agent`。

这是 AmazMe 第一个大版本的网页客户端。没有版本 1 标头的会话或 runtime 文件由宿主拒绝，页面不会迁移它们。

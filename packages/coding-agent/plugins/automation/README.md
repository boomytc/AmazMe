# 可选自动化插件

宿主通过已选包的 `server` facet 加载本插件。插件管理计划文件、定时检查和运行清理，会话仍由现有 worker 和 Harness 执行。未选择本插件时不读取计划、不创建定时器，Web 不显示自动化入口。

在宿主的 `pluginPackages` 中选择本目录，或在插件面板添加它并重启宿主。宿主包选择沿用持久 profile；已有会话的包选择保持自己的记录。默认原生 CLI 只加载 `session` 角色，本插件的 `server` 角色由宿主运行。

`src/server.ts` 通过本地 `HostSessions` 使用宿主的 agent 目录和会话执行接口，`src/runtime.ts` 负责当前的按分钟计划及 `Schedules` 服务。修改源码后重新启动宿主，会按原包构建流程生成并加载新的 bundle；内核和会话工具不需要为本插件增加执行器。

同一计划在运行时拒绝第二次手动或定时执行。删除计划、停止插件或关闭宿主会取消它已接纳的请求，并等待所属清理；其他排队用户输入保留。暂停只停止未来的定时触发，暂停期间仍可手动运行。

计划保存在 `<agentDir>/schedules.json`。格式损坏、无效记录或检测到外部修改时进入只读状态，拒绝新运行和文件变更；Web 显示问题和重新读取入口。修复文件后重新读取，恢复正常操作。外部内容比较用于检测修改，不作为跨进程的原子投递保证。

当前提供按分钟计划、手动运行和最后结果。一次性与日历规则、时区、忙碌及错过执行策略、逐次投递记录、跨宿主所有权和重启恢复继续在本插件内实施。

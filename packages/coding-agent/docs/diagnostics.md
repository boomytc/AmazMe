# 只读诊断

执行 `amazme doctor`，或在 Web 的「设置 → 文件 → 只读诊断」打开同一份本地报告。

```bash
amazme doctor --zh
amazme doctor --json
```

报告按需读取配置、凭据元数据、宿主与存储目录、MCP 配置和资源文件。它不会创建配置或锁目录，不执行密钥命令，不启动 MCP，不调用模型，不刷新 OAuth，也不自动修复文件。可复制的报告只包含明确构造的状态、名称和路径，不包含配置值、令牌、命令、请求头或原始解析错误。

CLI 观察当前工作目录和当前 agent 目录。项目配置遵守已保存的信任决定与全局默认信任策略，不运行扩展的信任钩子。Web 观察宿主的管理工作目录和 agent 目录，沿用该管理服务当前的信任决定；它同时报告页面入口和样式是否已加载。报告是一次观察，关闭后重新打开可读取新状态。

本地已配置不代表供应商已接受凭据，也不代表网络连通。密钥命令标为未执行；过期 OAuth 标明正常请求可能刷新，但诊断本身不刷新。OAuth 沿用 Pi 的客户端 ID、回调配置及供应商请求身份。IAM、ADC、自定义请求头、匿名与代理鉴权不会在诊断中解析。

目录检查使用读取、写入和访问权限判断，不通过创建探测文件测试权限。存储 JSON 检查语法与根结构；会话数据库保持关闭，报告明确区分目录可访问与数据库完整性。未选用的插件不会因诊断而激活；已选用的插件检查其 manifest 可读性，执行状态仍由插件自己的服务提供。

退出码：`0` 表示没有错误级条目，仍可能有过期凭据等提示；`1` 表示配置损坏、不可访问或必需资源缺失；`2` 表示命令参数无效。按报告中对应路径修复文件、权限或资源，再重新诊断。可选配置文件缺失时使用默认值；删除或覆盖前应自行保留原文件。

报告包含本地路径。分享前检查其中的路径和名称。
